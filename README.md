# BrainTumorDetection

PROBLEM STATEMENT:
To develop a hybrid deep learning framework that leverages Graph Neural Networks (GNNs) for effective brain tumor detection and classification from
MRI images by capturing both spatial and structural relationships among brain regions.


OBJECTIVES:
Effectively integrates CNN-based feature extraction with Graph Neural Network (GNN) modeling.
Converts MRI image patches into graph representation to capture both spatial and structural dependencies among brain regions.
Aiming a model to achieve robust, interpretable, high-accuracy brain tumor detection and classification across diverse MRI scans.


TOOLS AND TECHNOLOGIES:
1.Python
2.Google Colab
3.PyTorch
4.OpenCV
5.Matplotlib
6.Streamlit

DATASET:
Brain MRI Images for Brain Tumor Detection
The dataset has 98 (82 unique) images without a tumor and and 155 (140 unique) images with a tumor.
https://www.kaggle.com/datasets/navoneel/brain-mri-images-for-brain- tumor-detection/data


PIPELINE:
1.Data Acquisition and Preprocessing
2.Data augmentation
3.Patch Generation Module
4.CNN-based Feature Extraction Module
5.Graph Construction and Embedding Module
6.Graph Neural Network (GNN) Classification Module
7.Evaluation and Visualization Module
